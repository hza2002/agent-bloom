# microsoft prototype source

Silhouette: [Simple Icons 9.0.0](https://raw.githubusercontent.com/simple-icons/simple-icons/9.0.0/icons/microsoft.svg), CC0 collection.
This is a third-party vector transcription, not a direct official asset delivery.
Original SVG preserved here; terminal pixel adaptations and animation are project designs.
Brand trademarks remain with their owners.

## Adaptation

Four-colour square geometry is reconstructed from the saved silhouette. Text below it uses the host font, not an official wordmark. Mission excerpt source: https://www.microsoft.com/en-us/about

## Merged Windows / Microsoft direction

The static 42×42 panes use Microsoft colours and a four-pixel gutter. Each pane
passes through the same curved coordinate field to evoke a Windows flag, then
returns continuously to its exact square geometry. This is an original motion
and shape adaptation, not an official animation or an exact XP logo reproduction.
The old Windows module and its saved sources remain research material only and
are no longer in the active prototype catalogue.

All three footer lines originate from Microsoft official sources:
- Your potential Our passion: historical campaign quoted in the 2004 speech,
  https://news.microsoft.com/speeches/steve-ballmer-michigan-state-university/
- Achieve more: excerpt from the mission statement,
  https://www.microsoft.com/en-us/about
- We empower the world: heading on the same official About page

Punctuation is removed and case normalized. This project combines these lines;
they are not presented as one officially published slogan set.
