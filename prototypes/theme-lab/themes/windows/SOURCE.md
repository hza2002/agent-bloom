# Windows prototype sources

Current geometry: [Simple Icons 9.0.0 Windows XP](https://github.com/simple-icons/simple-icons/blob/9.0.0/icons/windowsxp.svg), CC0 collection, preserved in `xp.svg`.
This is a third-party transcription, not a direct official asset delivery.
`xp-paths.js` separates the four source subpaths, converting relative starting points to absolute coordinates. Four flat brand-inspired colours replace the monochrome fill. The large mark uses these contours. The badge is independent of the XP hero: four aligned square panes, with modern blue and four-colour options. These are optical terminal adaptations, not exact official SVG rasterizations.

The earlier Windows 95 source remains in `source.svg` for provenance but is no longer rendered.
Animation and footer copy are project designs. Brand trademarks remain with their owners.
